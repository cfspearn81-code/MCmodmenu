Real-client verification for Faster 1.4.0 on Minecraft 26.3/Fabric, with a disposable localhost vanilla server on 127.0.0.1:25568. The fixture uses actual production menu controls, KeyboardHandler key events, key mappings, MouseHandler's normal sensitivity/inversion/turn path, player input, camera alignment/frustum updates and outgoing movement/input packets. It does not replace the camera/input implementation or suppress packets. It supplies window focus and held key mapping states for deterministic testing. Blocked rendering/action branches are also inspected in source; this fixture is not an authenticated public-server test.

Checks: default F6 toggles, search resets/focuses on opening, all seven modules are reachable, P is accepted in a query, no-result state, Ctrl+A replacement, case-insensitive compact FreeCam matching, no body movement while typing, reserved-key rejection, binding an A–Z key, menu toggling, wall-crossing camera movement with stationary player/input/rotation, real mouse look independent of the body, fast diagonal flight, focus-loss pause, return to normal view, repeat/release not toggling, ordinary movement after disabling, inventory pause, original third-person perspective, death cleanup, and a cached Xray selection following camera translation while player position stays fixed.

During the first active flight the fixture observes real outbound ServerboundMovePlayerPacket and ServerboundPlayerInputPacket traffic. It asserts that camera position/rotation do not appear as player movement and that any transmitted player controls remain empty. A healthy player's normal heartbeat/physics packets continue; no networking bypass is installed. Later server teleport commands reset the disposable scene between cases, outside this audit period. Death is simulated by setting client test-player health to zero; it is not a server combat test.

Scene: BridgeLive is an OP offline test account, standing at 0.5,81,0.5 on a stone floor at Y80 spanning X=-8..8/Z=-8..120. A wall at X=-8..8,Y81..88,Z3..10 blocks ordinary walking. The prior dense Xray fixture's coal blocks at X=-32..31,Y65..96,Z8..39 may also remain in this disposable world. A diamond ore in the wall supplies Xray data for the translation check. A second view from above/behind inspects the player's visible body, normal camera return, and hidden detached hands. Screenshots are saved under /tmp/faster140-preview/screenshots and inspected after the run.

Compile src/ against the production client classes and Minecraft/Fabric development classpath, copy the two JSON resources into a clean fixture classes directory and jar it.
