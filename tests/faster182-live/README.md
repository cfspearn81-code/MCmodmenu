Existing BridgeEdgeGuardTest also passes all 77 swept-angle/retreat/gap checks. This is a controlled local vanilla rejection/latency test, not a test of an unknown third-party anti-cheat. It prevents trusting outstanding predictions and covers early post-ack rollback; server teleports, removal of already trusted ground beneath the actor, or a fall already underway cannot be guaranteed safe by a client edge guard.

The implementation reads vanilla's existing prediction-position map with constant-time membership checks, without scanning chunks or retaining another world-sized cache. All outstanding predictions are excluded from support, not just the expected Auto Bridge target. Normal BlockPlaceContext identifies replaceable-face targets. New reconciled footing stays excluded for four ticks and is rechecked for loss/new predictions. A pending/rejected safety latch keeps input/momentum protection after bridge-key release; release the bridge key and stop moving to clear a rejection latch, retreat to supported ground, or disable the module. No forced crouch, view changes, custom movement packets or server-position overrides are added.
