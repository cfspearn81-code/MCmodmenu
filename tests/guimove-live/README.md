Live verification for 1.3.5-ui.3 on Minecraft 26.3, using the real Fabric client and a disposable localhost vanilla server on port 25568. All ten movement cases passed; results.json records measured horizontal distances in blocks. Each case uses the actual native Screen class and production keyboard-input redirect. The fixture supplies held W at the lowest physical-key polling boundary and supplies focus state, so this tests gameplay movement rather than OS keyboard delivery. GuiMove does not consume text events: the chat case also verifies that typed W reaches the edit box. Disabled and unfocused cases remain stationary after initial settling; the release case confirms movement stops after release and normal inertia.

Inventory, crafting, chest, chat, pause, options and a generic screen all moved 13.56 blocks. Gui.isPausing is verified false with GuiMove on, and true for the same pause menu with the module off. This checks the predicate used by the single-player render/tick loop; the live run itself used a dedicated local server, not an integrated world.

Afterward, two client-only remote-player fixtures with real red/blue scoreboard teams are rendered by the production ESP renderer. Front and off-screen screenshots were visually inspected: both tracers and boxes/edge markers use the matching color. Screenshots are saved outside the checkout at /workspace/previews/guimove-ui.3/.

To rerun, compile these fixture sources against build/classes/java/client, build/classes/java/main and the Minecraft/Fabric development classpath, copy the two JSON resources into the fixture classes directory and jar it. Launch runClient with -Dfabric.addMods pointing to that JAR in JAVA_TOOL_OPTIONS, username BridgeLive, and a disposable online-mode=false server bound to 127.0.0.1:25568 with BridgeLive opped. Provide a stone floor at Y80 across X=-8..8, Z=-8..120 and force-load the area. The fixture teleports to 0.5,81,0.5 and exits automatically after screenshots. It changes test-client settings and must not be installed in a normal game. It is outside production source roots and is not in the release JAR.
