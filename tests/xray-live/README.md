The disposable Fabric client fixture validates Xray in a real 26.3 client connected to a vanilla localhost server on 127.0.0.1:25568 as offline user BridgeLive. It uses actual production chunk-load hooks, scanning, projection, GUI clicks and numeric key handling. It does not replace the scanner or renderer. It forces test-window focus, disables Auto Bridge/Auto Hit in the test client's settings, and changes Xray settings. Never install the fixture in a normal game.

The fixture asserts nine block-to-ore mappings, all seven deepslate variants, nether gold grouping, copper/deepslate copper exclusion, exact radius boundaries in all six directions, all nine menu toggles in both directions, typed ranges 1 and 5000, rejection of 5001, and a bounded loaded-chunk queue at radius 5000. It checks cached ores against server-supplied blocks, shrinking/restoring range, immediate client-side replacement updates, new ore discovery in a scanned empty section, and clearing the cache when disabled. The replacement check uses the real ClientLevel.setBlock path, not a second player's mining action. Standalone XraySettingsTest additionally checks defaults, invalid values, preservation and reload in a fresh JVM with isolated settings stubs.

For the local world, provide a stone floor at Y80 around 0,0, and op BridgeLive. Fill X=-8..8, Y=81..88, Z=3..10 with stone. Set blocks behind the front wall at Z6: X=-4,0,4 and Y82 for coal/iron/gold; Y84 for redstone/lapis/diamond; Y86 for emerald/nether_quartz/ancient_debris. Copper test blocks are at 6,83,6 and 6,85,6. At Z8,Y82 put the seven deepslate ore variants at X=-4..2 and nether gold at X3. Put diamond ore at 0,82,32. Force-load and send this area normally to the client. The fixture teleports to 0.5,81,0.5.

Compile src/ against the mod's client classes and Minecraft/Fabric development dependency classpath with JDK25; copy both JSON resources to fixture classes and jar them. Set -Dfabric.addMods=/absolute/path/to/fixture.jar in JAVA_TOOL_OPTIONS for runClient, using --username BridgeLive. SDL_VIDEODRIVER=offscreen and ALSOFT_DRIVERS=null permit a headless software-rendered run. Screenshots save under /tmp/xray-preview/screenshots; the fixture stops after 415 ticks and prints XRAY ALL CHECKS COMPLETE. The fixture lives outside production source roots and is not in the release JAR.
