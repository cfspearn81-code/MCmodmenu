# Current build

`faster-1.7.0-mc26.3.jar` is Faster 1.7.0 for Minecraft Java 26.3, Fabric Loader 0.20.1 or newer, and Java 25. It adds QuickJump (instant normal jump peak) to Movement, preserves the pause-screen blur crash fix and groups Xray, Player ESP, BedEsp and Free Cam under Visuals. It includes BedEsp with bed-colored outlines and editable range, QuickFall, Wall Climb with vanilla ladder physics, module search, Free Cam (F6 by default), optimized Xray and the existing tools.

Replace the previous mod JAR in your instance's `mods` folder; do not keep both versions installed. Existing preferences remain compatible. The adjacent `.sha256` file verifies the download. Earlier builds remain here for users who need them.

Source, changelog and validation records are included in this repository. The JAR is committed so its GitHub download remains available without temporary hosting.
