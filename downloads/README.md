# Current build

`faster-1.9.3-mc26.3.jar` is Faster 1.9.3 for Minecraft Java 26.3, Fabric Loader 0.20.1 or newer, and Java 25. Aim Lock now retains the same living target while its key is held, acquires nearby visible players ahead, and pauses through obstruction/menu/focus changes without switching players. Auto Bridge earns a one-tick check after three sustained confirmed placements, instead of repeating the 10–40 tick wait on every block. Separate server block confirmation and native acknowledgement remain mandatory; rejected/missing confirmations keep their edge protection. Recent approved footing is monitored for 100 ticks, and observed failures restore conservative checks. It preserves Aim Lock in Combat with a configurable hold key (R by default), retains the Sky Tint horizon fix and keeps Player Tint removed. Sky Tint retains its color sliders under Visuals. It preserves QuickJump, the pause-screen blur crash fix and the existing tools. It includes BedEsp with bed-colored outlines and editable range, QuickFall, Wall Climb with vanilla ladder physics, module search, Free Cam (F6 by default), optimized Xray and the existing tools.

Replace the previous mod JAR in your instance's `mods` folder; do not keep both versions installed. Existing preferences remain compatible. The adjacent `.sha256` file verifies the download. Earlier builds remain here for users who need them.
