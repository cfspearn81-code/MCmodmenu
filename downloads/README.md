# Current build

`faster-1.8.1-mc26.3.jar` is Faster 1.8.1 for Minecraft Java 26.3, Fabric Loader 0.20.1 or newer, and Java 25. It fixes the blue horizon band in Sky Tint and removes Player Tint. Sky Tint retains its color sliders under Visuals. It preserves QuickJump, the pause-screen blur crash fix and the existing tools. It includes BedEsp with bed-colored outlines and editable range, QuickFall, Wall Climb with vanilla ladder physics, module search, Free Cam (F6 by default), optimized Xray and the existing tools.

Replace the previous mod JAR in your instance's `mods` folder; do not keep both versions installed. Existing preferences remain compatible. The adjacent `.sha256` file verifies the download. Earlier builds remain here for users who need them.

Source, changelog and validation records are included in this repository. The JAR is committed so its GitHub download remains available without temporary hosting.
