Spawn NPC 1.0.0 live regression on a real Minecraft 26.3/Fabric client at 854×480 connected to a disposable vanilla localhost server, 127.0.0.1:25568, offline OP BridgeLive. The standalone run uses this project's own Gradle runClient, with no Faster loaded. A second run loads the exact standalone release JAR alongside Faster 1.9.4, using the same fixture and an additional Aim Lock compatibility check. No server plugin is installed. These are local tests, not public-server tests.

The fixture opens the real ChatScreen with `/spawnnpc` as its text and submits native Enter input. It checks the resulting client player entity, local ID/UUID, matching owner skin/main arm, independent equipment copies and clear ground placement. Native Minecraft left-click handling exercises ordinary hurt feedback/cooldown and diamond-block removal, including full removal from the entity map and player list without consuming the item. Offhand-only diamond blocks do not remove dummies. Repeated commands must create non-overlapping independent NPCs, and removing one must preserve the other.

Repeated attacks/right-clicks immediately after despawn must remain local. An injected entity-ID replacement checks that a stale dummy reference cannot remove another entity. Other cases cover right-click suppression for local dummy IDs, invalid-argument usage, forwarding unrelated commands, a real server armor-stand attack passing through normally while a diamond block is held, and cleanup on a real server-initiated dimension transition. A packet observer requires zero `/spawnnpc` command packets and zero attack/interact packets against local dummy IDs; ordinary commands and real server-entity attacks still send normally. Normal vanilla swing packets may still occur on clicks.

The standalone fixture supplies creative inventory equipment locally to check copies, creates its disposable arena/armor stand and performs the dimension transition through normal OP commands. It invokes no Faster code unless Faster is actually loaded. The integration run disables unrelated Faster modules and drives its R hold query through fixture input only, then verifies that production Aim Lock selects the mod's dummy as a normal player target. All production NPC spawn/interaction/cleanup code runs unchanged. All fixtures remain outside production roots and are excluded from the release JAR.

Compile src/ using JDK25 against built Spawn NPC client classes and the Minecraft/Fabric runtime classpath, copy fabric.mod.json/check.mixins.json into a clean fixture classes directory, and jar it. For standalone, launch the project's runClient with `-Dfabric.addMods=/absolute/path/fixture.jar` in JAVA_TOOL_OPTIONS, username BridgeLive, and the disposable offline OP server above. For integration, launch Faster's runClient with `-Dfabric.addMods=/absolute/path/spawnnpc-1.0.0-mc26.3.jar:/absolute/path/fixture.jar`. `SDL_VIDEODRIVER=offscreen` and `ALSOFT_DRIVERS=null` support cloud rendering. Results/screenshots go to /tmp/spawnnpc-live/. The fixture stops after NPC ALL CHECKS COMPLETE. Recorded result files distinguish standalone and integration runs.
